PICADS v0.16.8 r8 — SELECTIVE CO CONSTRAINTS

1. Shut down PICADS.
2. Extract this patch directly over your existing PICADS installation,
   for example C:\ChipManuSoftware\PICADS Build, with overwrite permitted.
3. Do not remove dependencies, Docker Desktop, Ubuntu, installed PDKs or projects.
4. Run PICADS, and compile examples/co_selective_enforcement (no external EDA required).
5. If the real WSL/SKY130 environment is working, generate GDS for that demo.
6. Inspect build/latest/module_floorplan.json and config.json; the latter must
   include FP_OBSTRUCTIONS for requested hard keepouts.

IMPORTANT: This is a PARTIAL implementation of your core CO enforcement goal.
Actual hard ALU/memory module fences are not yet supported. Setting module
`enforcement: required` explicitly BLOCKS generation rather than lying that
its cells obey CO rectangles. See docs/CO_SELECTIVE_PHYSICAL_CONSTRAINTS.md.

The patch also includes the r7 KLayout `-lx` visibility fix.
